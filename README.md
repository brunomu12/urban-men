👕 Urban Men

Ecommerce de indumentaria masculina

Urban Men es un proyecto de ecommerce desarrollado como Trabajo Integrador para la asignatura Aplicaciones Web 1.

El sitio permite visualizar productos de indumentaria masculina organizados por categorías, con una interfaz sencilla y una identidad visual basada en los colores negro, dorado y blanco.

🌐 Sitio publicado

Visitar Urban Men

💻 Tecnologías utilizadas

HTML5: estructura de las páginas.

CSS3: diseño, estilos y presentación visual.

JavaScript: funcionalidades e interacción con el usuario.

JSON: organización y almacenamiento de los datos de productos.

GitHub: administración del código fuente.

GitHub Pages: publicación del proyecto.

🛍️ Funcionalidades

Página principal con productos.

Navegación entre categorías.

Secciones de remeras, sweaters, camperas y jeans.

Tarjetas de productos generadas dinámicamente.

Visualización de información de los productos.

Selección de cantidades.

Formularios de inicio de sesión y registro.

Barra de navegación reutilizable.

Funcionalidad de cierre de sesión.

Categorías

-Remeras

-Sweaters

-Camperas

-Jeans

🛠️ Desarrollo del proyecto

El ecommerce se desarrolló en cuatro etapas:

Estructura HTML: creación de las páginas y organización del contenido.

Diseño CSS: implementación de la identidad visual y estilos.

JavaScript: creación de componentes y funcionalidades dinámicas.

JSON: integración de los datos de productos y visualización por categorías.

🎯 Objetivo

Desarrollar un ecommerce funcional aplicando los conocimientos adquiridos durante la cursada de Aplicaciones Web 1.
